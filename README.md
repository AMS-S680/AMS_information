## 下载全部资料

PDF、PPTX、WAV、MP3 和 FLAC 通过 Git LFS 存储。请先安装 [Git](https://git-scm.com/downloads) 和 [Git LFS](https://git-lfs.com/)，再执行：

```sh
git lfs install
git clone https://github.com/AMS-S680/AMS_information.git
cd AMS_information
git lfs pull
```

若下载的文档或录音仅有约 130 字节，且以 `version https://git-lfs.github.com/spec/v1` 开头，说明取得的是指针，需执行 `git lfs pull` 下载文件实体。网页 ZIP 是否包含 LFS 实体取决于仓库设置。

已克隆仓库时，可执行 `git pull --ff-only` 和 `git lfs pull` 更新。

### AMSC5710 · 先进材料表征

围绕材料的成分、结构与电子性质，学习现代材料表征的基本原理、仪器操作和数据分析。内容涵盖以 X 射线、电子束和离子束为探测源的分析方法，包括表面光谱、衍射、电子显微和质谱；本地课件进一步涉及 XPS、UPS、AES、SEM、TEM 及电子能量损失谱等技术。

- **授课老师：**李泉（Prof. Quan LI），物理系。
- **邮箱：**[liquan@cuhk.edu.hk](mailto:liquan@cuhk.edu.hk)。[官方教师页面](https://app.phy.cuhk.edu.hk/teaching-staff/li-quan/)
- **资料入口：**[课程目录](<AMSC5710_Advanced Materials Characterization/>) · [课程介绍](<AMSC5710_Advanced Materials Characterization/EN/1.CourseIntroduction_5710(1).pptx>)。

### AMSC5720 · 先进材料合成

从材料结构与性质的基础出发，介绍金属、合金、陶瓷、聚合物及复合材料的制备，再延伸至半导体、纳米材料、智能材料、生物材料和电池材料等先进体系。重点理解合成与加工的科学原理、工艺放大和质量控制，并通过案例了解前沿制备方法。

- **授课老师：**陈也（Prof. Ye CHEN），化学系。
- **邮箱：**[yechen@cuhk.edu.hk](mailto:yechen@cuhk.edu.hk)。[官方教师页面](https://chem.cuhk.edu.hk/people/academic-staff/cy/)
- **资料入口：**[课程目录](<AMSC5720_Advanced Materials Synthesis/>) · [2026–27 课程介绍](<AMSC5720_Advanced Materials Synthesis/EN/AMS5720_Course Introduction_AY26-27.pdf>)。

### AMSC5730 · 先进材料前沿

由物理系和化学系多位教师分专题授课，通过讲座、案例分析和讨论建立跨领域的材料科学视野。课程关注先进材料的设计、性质及应用；本学年专题包括半导体与晶体生长、光催化、光伏材料、胶体与界面、超材料、无机纳米晶、等离激元、手性材料和有机电子学。

### AMSC5738 · 表面科学与薄膜技术

介绍表面科学、薄膜制备、表征与物理性质，强调用基本原理分析实验和工艺问题。内容涵盖真空科学与技术、表面反应的热力学和动力学、薄膜沉积、成核与生长模式、外延、薄膜表征及物性，并选讲薄膜制备与性质的前沿研究。

- **授课老师：**王建方（Prof. Jianfang WANG），物理系。
- **邮箱：**[jfwang@phy.cuhk.edu.hk](mailto:jfwang@phy.cuhk.edu.hk)。[官方教师页面](https://wp.phy.cuhk.edu.hk/teaching-staff/wang-jianfang/)

## 下载全部资料

PDF、PPTX、WAV、MP3 和 FLAC 通过 Git LFS 存储。请先安装 [Git](https://git-scm.com/downloads) 和 [Git LFS](https://git-lfs.com/)，再执行：

```sh
git lfs install
git clone https://github.com/AMS-S680/AMS_information.git
cd AMS_information
git lfs pull
```

若下载的文档或录音仅有约 130 字节，且以 `version https://git-lfs.github.com/spec/v1` 开头，说明取得的是指针，需执行 `git lfs pull` 下载文件实体。网页 ZIP 是否包含 LFS 实体取决于仓库设置。

已克隆仓库时，可执行 `git pull --ff-only` 和 `git lfs pull` 更新。
